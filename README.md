# Rising Arts website

Website for **Rising Arts**, a wall painting and outdoor advertising company at Ganesh Complex, Tirunelveli Junction.

Live site: https://rising-arts.vercel.app/ (deployed by Vercel from the `main` branch)

| File | What it is |
| --- | --- |
| `index.html` | The whole website: page, styles and script in one file |
| `images/` | Photos for the **Our Work** gallery – see `images/README.md` |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Browser tab and home-screen icons |
| `og-image.png` | Picture shown when the link is shared on WhatsApp or Facebook |
| `sitemap.xml`, `robots.txt` | Tell search engines which pages to index |
| `GOOGLE-SETUP.md` | Steps to get the business listed on Google Search and Maps |
